# 已知问题与待确认事项

## 已知限制

1. 项目默认使用本地 MySQL 和本机回环地址，未形成生产级部署包。
2. 迁移文件包含历史中文编码异常的规则名称插入文本；当前数据库中的规则名称已修复，但应在下一次版本化迁移中清理脚本并验证字符集。
3. 部分 Java 源文件中的用户提示文本存在历史编码异常，功能逻辑可执行，但提示文案应单独复核。
4. 项目有迁移 SQL，但未发现 Flyway 或其他自动版本执行机制；执行迁移依赖人工流程。
5. 未发现外部通知、外部系统同步、正式统计报表和通用导出模块。
6. 数据库快照、日志和本地运行目录属于运行资料，不应提交敏感内容或作为生产备份替代品。

## 待确认业务问题

- 余额、欠费和账期的正式财务口径。
- 空值主动清除的授权和操作方式。
- Excel 模板版本兼容及字段变更流程。
- 风险规则调整是否需要审批、历史版本保留多久。
- 任务提醒渠道、频率和失败重试。
- 多用户组织、部门和数据范围的最终模型。

## 维护建议

优先修复迁移脚本和源码提示的字符编码问题，建立可重复的数据库迁移工具链，再扩展报表、导出和通知。任何结构变更前应备份并验证备份可读，任何规则变更应保留版本和重算记录。
