# 技术归档说明

本目录保存项目早期的技术盘点、部署步骤、数据库说明和已知问题，主要用于追溯现有代码和本地运行环境。

当前业务需求以根目录 [`REQUIREMENTS.md`](../../REQUIREMENTS.md)、[`docs/independent-excel-ledgers/project-design.md`](../independent-excel-ledgers/project-design.md) 和 `openspec/specs/` 为准。归档资料中关于旧客户台账、风险规则、任务流程或旧 Excel 模板的内容，不应覆盖当前两套独立 Excel 台账的要求。

归档中的 API 清单、数据库结构和初始化命令描述的是旧版本，不可作为当前接口或迁移步骤使用。当前启动、数据库初始化、测试和备份说明请查看根目录 [`README.md`](../../README.md) 与 [`AI_GUIDE.md`](../../AI_GUIDE.md)；执行迁移前必须备份并确认目标数据库。
