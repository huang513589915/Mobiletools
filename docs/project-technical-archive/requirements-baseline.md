# 需求与实现状态基线

## 状态说明

已实现表示源码和至少一项测试或运行验收有依据；部分实现表示存在代码但范围或验证不完整；未实现表示本次未发现实现；待确认表示缺少可靠业务资料。

| 编号 | 当前需求 | 实际实现 | 验证状态 | 备注 |
|---|---|---|---|---|
| R-01 | 用户登录、退出、未登录保护 | Spring Security Session、登录/退出/CSRF 接口和页面 | 已实现 | 密码通过编码器校验；不记录密码 |
| R-02 | 管理员与客户经理权限 | 角色检查、客户范围表、管理员维护接口 | 已实现 | 复杂 RBAC 未实现 |
| R-03 | 客户台账查询 | 客户列表、详情、分页筛选及关联风险/业务展示 | 已实现 | 以真实接口为数据源 |
| R-04 | 业务、欠费和到期查询 | `/api/ledger` 查询接口和前端列表 | 已实现 | 外部同步未实现 |
| R-05 | 五类 Excel 数据处理 | POI 预检、预览、确认、批次、行和异常记录 | 已实现 | 长期模板变更仍需适配 |
| R-06 | 重复导入与关联失败控制 | 文件/业务幂等、客户关联校验、剔除及错误追踪 | 已实现 | 以代码和导入验收脚本为依据 |

| R-11 | 审计与异常核查 | 审计查询、异常列表、批次/行定位 | 已实现 | 审计内容和保留周期未配置化 |
| R-12 | 统计、导出、提醒 | 本次未发现完整独立实现 | 未实现/待确认 | 作为后续版本范围 |

## 与历史设计的主要差异

历史文档提出过外部系统接入、复杂权限、提醒和更完整导出能力；当前实现保持本地模块化单体，使用 Spring JDBC，不包含这些扩展。历史文档中的数据库设计比当前实现更偏规划性，实际字段和约束以 [database-design.md](database-design.md) 为准。

## 待确认事项

1. MySQL 精确版本及正式运行环境。
2. 五类 Excel 的长期版本、列变更策略和业务唯一性维护人。
3. 风险规则的生效时间、历史重算保留策略和提醒渠道。
4. 统计口径、导出范围和脱敏要求。
5. 外部系统接口及其认证方式。
