## 3. 首期占位规则

1. `customerId` 只用于 Demo 内部关联，不能作为正式客户唯一标识。
2. `businessDescription` 只用于展示，不能直接作为正式业务唯一标识。
3. 首期重复导入默认先标记为“重复/待核查”，不自动覆盖正式台账。
4. 未明确唯一标识、来源优先级和覆盖字段前，不执行静默覆盖。
5. 无法匹配或字段冲突的记录进入异常核查，不自动修改已确认数据。
