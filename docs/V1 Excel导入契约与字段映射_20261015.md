# V1 Excel 导入契约与字段映射

日期：2026-10-15

变更：define-local-mvp-requirements-v2

## 1. 适用范围

本契约基于 2026-10-15 对项目目录外部提供的五份最新 Excel 文件进行只读预检形成。文件只作为导入输入，不作为项目内敏感数据副本提交。

支持两种输入形式：

1. 一个包含五类业务工作表的标准工作簿。
2. 五个独立 Excel 文件，按表头识别业务类型。独立文件的实际工作表名称可以是 `Sheet1`，业务类型由表头映射确定。

当前实现使用 Apache POI 5.2.5 解析 `.xlsx`，预检和正式确认分离。

## 3. 表头和字段契约

### 3.1 客户基础信息

| 顺序 | 表头 | 类型 | 必填 | 规则 |
| ---: | --- | --- | --- | --- |
| 1 | 客户编号 | 文本 | 是 | 作为客户候选业务标识，不能为空 |
| 2 | 客户名称 | 文本 | 是 | 不能为空 |
| 3 | 客户类型 | 文本 | 否 | 空值更新时不覆盖原有效值 |
| 4 | 责任客户经理 | 文本 | 是 | 不能为空；如能唯一匹配启用账号则建立客户范围 |
| 5 | 联系电话 | 文本 | 否 | 保留原始文本，空值不覆盖 |
| 6 | 客户地址 | 文本 | 否 | 空值不覆盖 |
| 7 | 接入专线总数 | 非负整数 | 否 | 不能为负数 |
| 8 | 最近更新日期 | 日期 | 是 | 支持 `yyyy-MM-dd` 及可读取的 Excel 日期值 |
| 9 | 数据来源 | 文本 | 否 | 记录来源，不作为客户唯一标识 |
| 10 | 备注 | 文本 | 否 | 空值不覆盖 |

### 3.2 欠费账单明细

| 顺序 | 表头 | 类型 | 必填 | 规则 |
| ---: | --- | --- | --- | --- |
| 1 | 账单编号 | 文本 | 是 | 账单候选业务标识 |
| 2 | 客户编号 | 文本 | 是 | 必须能关联正式客户或同批次有效客户 |
| 3 | 账期 | `yyyy-MM` 文本 | 是 | 必须可解析为年月 |
| 4 | 出账日期 | 日期 | 是 | 日期格式有效 |
| 5 | 应缴金额(元) | `DECIMAL(18,2)` | 是 | 非负，最多两位小数 |
| 6 | 已缴金额(元) | `DECIMAL(18,2)` | 是 | 非负，不能大于应缴金额 |
| 7 | 欠费金额(元) | `DECIMAL(18,2)` | 否 | 必须等于应缴金额减已缴金额；由系统校验 |
| 8 | 缴费截止日 | 日期 | 是 | 日期格式有效 |
| 9 | 账单状态 | 文本 | 否 | 按原始值保存 |
| 10 | 导入批次号 | 文本 | 是 | 来源批次业务标识，不替代系统批次主键 |

欠费金额的正式计算为：`应缴金额 - 已缴金额`。负金额、已缴大于应缴、金额精度超过两位、超出 `DECIMAL(18,2)` 或公式结果无法读取时，行标记为无效。

| 7 | 服务到期日 | 日期 | 是 | 日期有效 |

| 9 | 续签状态 | 文本 | 否 | 空值不覆盖 |
| 10 | 最近跟进日 | 日期 | 否 | 有值时必须是有效日期 |
| 11 | 备注 | 文本 | 否 | 空值不覆盖 |

| ---: | --- | --- | --- | --- |
| 1 | 记录编号 | 文本 | 是 | 记录候选业务标识 |
| 2 | 客户编号 | 文本 | 是 | 必须关联正式客户 |
| 3 | 关联业务编号 | 文本 | 否 | 有值时按业务编号关联 |
| 4 | 任务类型 | 文本 | 是 | 不能为空 |
| 5 | 任务标题 | 文本 | 是 | 不能为空 |

### 3.5 预警规则配置

| 顺序 | 表头 | 类型 | 必填 | 规则 |
| ---: | --- | --- | --- | --- |
| 1 | 规则编码 | 文本 | 是 | 仅允许 R001、R002、R003、R004 |
| 2 | 规则名称 | 文本 | 否 | 规则名称由当前规则版本保留 |
| 3 | 阈值参数 | 文本表达式 | 是 | 必须包含数字和与规则一致的比较符 |
| 4 | 触发等级 | 文本 | 否 | 当前风险规则服务负责最终取值 |
| 5 | 说明 | 文本 | 否 | 记录来源说明 |

V1 正式规则：

| 编码 | 含义 | 比较符 | 默认阈值 |
| --- | --- | --- | ---: |
| R001 | 余额预警 | `<` | 500 元 |
| R002 | 累计欠费预警 | `>` | 1000 元 |
| R003 | 距离到期预警 | `<=` | 30 天 |
| R004 | 任务超期预警 | `>` | 1 天 |

管理员可以修改阈值，但系统必须创建新规则版本并保留旧版本。Excel 规则表达式必须保留正确比较符，不能只上传一个与规则语义不一致的数字。

## 4. 导入分类和写入规则

预检结果分为新增、更新、重复、冲突、无效和剔除。预检、预览和正式确认分离，取消预检不改变正式业务数据。

1. 同一文件通过 SHA-256 指纹禁止重复创建有效批次。
2. 同一业务标识和相同内容分类为重复，不生成重复正式记录。
3. 同一批次相同业务标识但内容不同分类为冲突，不能静默覆盖。
4. 非必填 Excel 空值默认不覆盖已有有效值。主动清空需要后续明确的专门操作。
5. 欠费账单、专线、到期和跟进引用不存在客户时，只进入剔除或异常明细，不进入正式账单、任务或客户台账。
6. 每个批次记录总行数、成功数、更新数、重复数、剔除数、失败数，并保留工作表、原始行号、业务标识和错误原因。
7. 正式批量写入在事务内执行。不可恢复错误回滚业务写入，保留失败批次和行级错误。
