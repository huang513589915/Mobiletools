# V1 任务来源与幂等阶段验证

任务创建现在支持客户、业务专线、欠费账单、业务到期、风险结果和开放异常来源。来源必须属于正式客户且与客户编号一致；剔除记录、失效来源、孤立客户和越权客户不能创建正式任务。

同一客户、来源记录和任务类型的未结束任务会复用；完成或关闭后允许同一来源重新建立任务。客户行锁和任务加锁当前读保护并发创建。任务详情展示来源类型、来源编号和任务类型，风险结果可打开关联任务。
